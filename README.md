# 路面裂缝两层卷积 · 边缘分块尺寸选型演示

FastAPI + NumPy（全程 float64）实现的网页小工具：上传一张每边至多 512 像素的
灰度 PNG 和两层卷积的权重/偏置 JSON，在给定的第一层输入激活预算下，从
1～64 中选出预算允许的最大**方形输出分块边长**，并分别用分块推理和独立整图
基准跑分，报告峰值用量、最大绝对误差及其坐标，误差 > 1e-8 判失败。

## 网络结构（固定）

| 层 | 通道 | 核 | 步长 | 膨胀 | 零填充 | 激活 |
|---|---|---|---|---|---|---|
| layer1 | 1 → 4 | 3×3 | 2 | 1 | 1 | ReLU |
| layer2 | 4 → 1 | 3×3 | 1 | 2 | 2 | — |

## 预算口径与选型规则

- 对每个输出分块（边缘块按实际输出尺寸**裁短**），沿两层感受野链路反推出
  覆盖它所需的**图内激活最小矩形窗口**，元素数 = 窗口高 × 窗口宽 × 输入通道数；
  图外零填充不物化、不计入。
- 窗口公式（layer2 dilation 2，输出 `i` 只读 layer1 输出 `i−2, i, i+2`）：
  1. 先求该块依赖的 **layer1 输出矩形**（闭区间）：
     - 含 ≥2 个输出：相邻 tap 集合首尾相接，并集 `[a0−2, a1+1]`；
     - 单像素块：`{a0−2, a0, a0+2}` 有空隙，取**有效 tap 的最小/最大值**；
     - 两种情形都裁到有效输出界 `[0, ho)`／`[0, wo)`——越界 tap 是 layer2
       零填充，不读任何图内激活。
  2. 再经 layer1（stride 2）映射到输入：闭区间 `[kmin, kmax]` →
     半开窗口 `[2·kmin−1, 2·kmax+2)`，最后裁到图界。
- 边长 `s` 的峰值 = 该 s 下**全网格所有分块**窗口元素数的最大值：行方向取
  最大窗口高、列方向取最大窗口宽后相乘（两轴可分离，结果与逐块枚举一致）。
  边缘块按实际输出裁短后单独计算，不会因抽查角块/中块而漏掉更大的块。
  从 1～64 中选峰值 ≤ 预算的最大 s。
- 实跑时分块路径截取的正是同一窗口；流水线对“实跑峰值 == 规划峰值且
  ≤ 预算”做硬性断言，守住预算。两者使用同一 `required_layer1_window` /
  `required_input_window` 函数，避免口径漂移。
- 当单像素块（s=1）仍超预算时，**不执行推理**，只返回真实最低所需预算
  （即 s=1 网格峰值）；网页与 JSON 对该结论一致。
- 可行时继续与独立整图基准（整图零填充 + 滑窗求和）比对，最大绝对误差
  > 1e-8 判失败。

## 运行方式

### Docker Compose（推荐）

```bash
docker compose up --build
# 浏览器打开 http://localhost:8000
```

### 本地 Python（3.11+）

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 权重 JSON 格式

```json
{
  "layer1": {"weight": [[[[...3x3...]]]], "bias": [0, 0, 0, 0]},
  "layer2": {"weight": [...形状 1x4x3x3...], "bias": [0]}
}
```
形状要求：layer1.weight `(4,1,3,3)`、layer1.bias `(4,)`、
layer2.weight `(1,4,3,3)`、layer2.bias `(1,)`。

### 样例

`scripts/make_samples.py` 生成确定性样例（已随仓库提供于 `samples/`）：

```bash
python3 -I scripts/make_samples.py samples
# sample_crack_64.png（64×64 裂缝灰度图）
# sample_random_8.png（8×8 随机图，便于手工核对窗口）
# weights.json（两层权重与偏置）
```

页面上传两个文件并填入预算（元素数）即可；勾选“以 JSON 返回”便于脚本调用。
